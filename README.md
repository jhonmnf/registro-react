# Estudos de Componentes React

Projeto de aprendizado com React e Vite, voltado à criação de componentes, passagem de propriedades e renderização condicional.

O código atual é um exercício de componentes. Um sistema completo de registro de ponto ainda não está implementado.

## Executar localmente

A aplicação está na pasta `registro.ponto/`. Instale uma versão do Node.js compatível com o Vite definido no arquivo de lock.

```bash
cd registro.ponto
npm ci
npm run dev
```

Abra o endereço informado pelo Vite.

## Verificar o projeto

Na pasta `registro.ponto/`:

```bash
npm run lint
npm run build
```

## Estrutura

- `registro.ponto/src/App.jsx`: componente principal.
- `registro.ponto/src/app/Layout.jsx`: componentes e exemplos de propriedades.
- `registro.ponto/src/App.css` e `src/index.css`: estilos.
- `registro.ponto/package.json`: dependências e comandos.

## Status
